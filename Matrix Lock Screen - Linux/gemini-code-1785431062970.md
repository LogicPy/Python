# 🟩 Matrix Terminal Lock Screen (GTK3 / Python)

A high-security, full-screen custom lock interface built for Pop!_OS and Linux desktop environments. Features dynamic Matrix code rain animations powered by Cairo rendering, direct native C-level PAM authentication, and compositor-level security hooks to prevent bypass.

---

## 🔥 Key Features

* **Matrix Code Rain Canvas:** Smooth ~30 FPS persistent off-screen surface rendering using Japanese Katakana and symbols via Cairo graphics.
* **Native PAM Authentication:** Directly verifies user credentials against `libpam.so.0` using C-level `ctypes` bindings.
* **Multi-Monitor Native Support:** Automatically detects display boundaries and stretches visual overlays across secondary screens seamlessly.
* **Full Window & OS Bypass Interception:**
  * Blocks `Alt + F4` and standard GTK close signals (`delete-event`).
  * Captures hardware inputs via `Gdk.GrabOwnership.NONE`.
  * Intercepts `Gdk.KEY_Super_L` / `Gdk.KEY_Super_R` keypress events.
  * Dynamically toggles Gnome/Mutter `overlay-key` via `gsettings` to fully lock down Pop!_OS system shell launcher overlays while active.
* **Custom CSS Styling:** Deep dark modern card interface with neon terminal aesthetics.
